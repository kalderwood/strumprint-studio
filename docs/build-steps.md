# Strumprint Studio: build steps

**Step 0: Set up the project.** GitHub repo, Unlicense (public domain), automatic license check that only allows MIT, Apache, BSD, ISC and 0BSD libraries.

**Step 1: Input picker.** Choose your interface input (cable or mic), level meter, tuner. Browser voice processing switched off. *(done)*

**Step 2: Test clips in Audacity, plus a "play a file" mode.** *(play-a-file mode done)*

**Step 3: Live single notes.** *(done)*

**Step 4: Live tab.** Easiest string and fret, tuning and capo settings. *(done)*

**Step 5: Sheet music.** VexFlow staff with linked tab, in time with a metronome.

**Step 6: Chord library.** Chord definitions from tonal.js plus community chord shapes from `chords/`.

**Step 7: Chord detection.** Basic Pitch hears the ringing notes and the app matches the closest chord, scored against the Audacity test clips.

**Step 8: Circle of fifths.** Key guess, related chords, progression trace. *(first version done)*

**Step 9: Exports.** MusicXML, MIDI and PDF, checked in MuseScore Studio.

**Step 10: Release and open the community.** GitHub Pages, contribution guide, automatic checks on pull requests.
