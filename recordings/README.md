# Chord recordings

Recordings are the test set that proves chord detection works on many guitars, mics and players. Large audio files will move to a separate repo once the collection grows.

## Recording method (record in Audacity)

1. **Pick each string one at a time**, low to high, letting each ring for about a second.
2. **One slow strum**, letting it ring out.
3. **Three normal strums** at a steady tempo.
4. Leave **one second of silence** at the start and end.

Export as WAV, mono, 44.1 kHz. Name files like `C_major__open__DI__yourname.wav` (DI = direct cable, MIC = microphone). If you can, record each chord once with the cable and once with a mic.
